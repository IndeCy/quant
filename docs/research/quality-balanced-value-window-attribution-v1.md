- 归因标签：`VALUE_EXTENSION_DRAG`
- 解释：加入E/P与B/P后，窗口中位Sharpe相对纯Quality下降至少0.05。
- 纯Quality窗口中位Sharpe：0.389
- 纯E/P窗口中位Sharpe：0.020
- 纯B/P窗口中位Sharpe：-0.109
- 原策略窗口中位Sharpe：0.242
- 估值扩展对Quality的窗口中位Sharpe边际：-0.099
- Quality对纯估值的窗口中位Sharpe边际：+0.161

结论：该结果用于解释既有低效窗口，不构成删因子、改权重或策略晋级依据。
