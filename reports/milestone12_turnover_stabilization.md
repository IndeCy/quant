# Milestone 1.2 交易结构压缩与组合稳定化报告

## 一、改造说明

- 未修改 M0 `ExecutionModel`，成交仍按 T+1、佣金、印花税、滑点、停牌、涨跌停和无效价格拦截执行。
- 未改变动量、低波、趋势的因子定义；改造只发生在“因子排名 -> 目标权重”的组合构建层。
- 新增模块：`backtest/portfolio_construction.py`。
- 改造入口：`PriceFactorRotationStrategy` 增加可选稳定化组合构建；研究脚本直接复用同一构建器。
- 替换逻辑：原 `Top20 等权` 可替换为 `Core-Satellite + rank band + 换手约束`。

### 新结构规则

- Holding Inertia：旧持仓仍在样本池排名 Top40% 内优先保留，不因短期掉出 Top20 立即卖出。
- Turnover Smoothing：每月最多替换 20% 成分，至少尽量保留 60% 上期持仓。
- Turnover Constraint：目标权重单边月换手超过 30% 时，继续减少新进卫星仓。
- Core-Satellite：延续持仓作为 Core 占 70%，新进 Top20 差集作为 Satellite 占 30%。

- 频繁进出同一股票：新结构通过 Top40% rank band 保留旧持仓，减少了掉出 Top20 但仍处于候选区间的被动卖出。
- 噪声交易：每月只允许部分卫星仓更新，避免因排名边际变化导致整组重排。
- 回撤期震荡：换手上限会优先保留原持仓，降低回撤期反复加仓/减仓的交易噪声，但不会消除价格因子自身的风格回撤。

## 六、结论

1. 换手显著下降：三类策略平均月换手平均降幅为 82.33%。
2. 新结构显著提高持仓周期：三类策略平均持有天数平均提升 1615.93%。
3. 隐性高频交易判断：未发现明显隐性高频交易。判断依据是新结构 <1个月生命周期占比是否仍高于 30%。
4. Alpha 保留情况：新结构平均保留原年化收益约 162.79%，研究重点是交易可执行性而不是收益优化。
5. 最接近可实盘长期持有模型：低波动 新结构。该结论同时参考平均持有天数和月度持仓保留率。
6. 是否进入 Milestone 2：可以进入。新结构把组合从每月噪声重排压缩为 Core-Satellite 的长期持有结构，更适合承接后续基本面因子。
