# Phase E2.1：Data Catalog Plan

## 目标

建立轻量 Data Catalog，统一记录本地 DuckDB/SQLite 数据资产，服务三个目标：

1. 迁移到 Mac mini 时知道必须备份哪些数据。
2. 前端可以查看数据源、最新日期、表结构和质量状态。
3. 后续 Data Quality Gate 可以基于目录做阻断检查。

## 非目标

- 不改行情数据存储口径。
- 不新增外部数据源。
- 不做复杂元数据平台。
- 不引入服务端数据库，继续使用本地 SQLite 状态库。

## 实现任务

1. 新增 `runtime/data_catalog.py`
   - 扫描 DuckDB/SQLite。
   - 提取表名、字段、行数、日期字段和最新日期。

2. 新增 `runtime/data_catalog_repository.py`
   - 保存 `data_sources`。
   - 保存 `data_source_tables`。

3. 新增 `runtime/data_catalog_runner.py`
   - 默认扫描根目录一层数据库文件和 `data/`。
   - 支持显式传入扫描目录。

4. 新增 `scripts/refresh_data_catalog.py`
   - 支持命令行刷新。

5. 接入本地 API
   - `POST /api/data/catalog/refresh`
   - `GET /api/data/sources`
   - `GET /api/data/sources/{dataset_id}`

- 能提取表级字段和最新日期。

- 本地 API 可以读取数据源列表和详情。
