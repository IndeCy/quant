# Phase E1.1 Experiment Runner Plan

## 背景

当前研究脚本和报告已经很多，但缺少统一实验登记。企业级系统需要知道每次研究用了什么配置、什么数据口径、什么时间窗口、输出了哪些结果和报告。

## 目标

- 新增实验登记模型。
- 新增实验运行记录。
- 新增实验产物索引。
- 提供最小 CLI，可登记一次手工实验。
- 不改变任何策略逻辑。

## 非目标

- 不实现 Walk-Forward 算法，留给 E1.2。
- 不重构现有研究脚本。
- 不改前端页面。
- 不新增因子。

## 数据模型

### experiments

- experiment_id
- name
- category
- status
- owner
- description
- config_json

### experiment_runs

- run_id
- experiment_id
- run_date
- status
- config_json
- metrics_json
- output_dir
- message

### experiment_artifacts

- artifact_id
- run_id
- artifact_type
- file_path
- title

## TDD 验收

1. 可注册实验定义。
2. 可记录一次实验运行。
3. 可登记实验产物。
4. 可查询实验详情和最近运行。
5. CLI 能生成一次 manual experiment 运行目录和 summary。

## 文件计划

- `runtime/experiment_repository.py`
- `runtime/experiment_runner.py`
- `scripts/run_experiment.py`
- `tests/test_experiment_runner.py`
