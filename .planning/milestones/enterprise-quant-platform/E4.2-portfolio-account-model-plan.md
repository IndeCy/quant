# Phase E4.2：Portfolio & Account Model Plan

## 目标

建立统一 Portfolio & Account Model，用来表达策略目标组合、实际持仓、现金、账户总资产和漂移。后续前端可以基于这套模型展示“理论应该持有什么、当前实际持有什么、需要调多少”。

## 非目标

- 不接券商接口。
- 不自动下单。
- 不修改策略 Alpha。
- 不改变 M0 ExecutionModel。
- 不替代已有 paper trading 历史，只新增统一视图层。

## 第一版能力

1. 保存账户快照
   - strategy_id
   - trade_date
   - total_value
   - cash
   - target holdings
   - actual holdings

2. 计算漂移
   - symbol 级 target_weight
   - actual_weight
   - drift_weight
   - drift_amount

3. 输出调仓差异
   - buy/sell/hold
   - target_amount
   - actual_amount
   - trade_amount

4. 状态库持久化
   - account_snapshots
   - account_positions

## 实现任务

1. 新增 `runtime/portfolio_account.py`
   - 纯计算：快照、漂移、调仓差异。

2. 新增 `runtime/portfolio_account_repository.py`
   - 保存账户快照和持仓。
   - 读取最近账户状态。

3. 扩展 `SystemRepository`
   - 组合 portfolio account mixin。

4. 接入本地 API
   - `GET /api/accounts/{strategy_id}`
