# Enterprise Quant Platform Project

## 项目定位

把当前个人 A 股量化系统升级为企业级研发与运行平台。短期目标不是自动下单，而是先做到数据可信、研究可复现、策略可治理、风控可追溯、运行可恢复。

## 当前基线

- 可信回测 M0 已完成：交易日历、T+1、成本、涨跌停/停牌拦截、统一复权/as-of 基础。
- Shadow Live 初版已完成：每日数据、策略、投研、风险、watchdog 调度。
- 策略资产化初版已完成：Quality Alpha V1、主线链动因子 V1。
- 前端与本地 API 已有雏形，但还不是完整平台。

## 企业级目标

1. 数据治理：可追溯、可校验、可迁移、可回放。
2. 因子平台：因子定义、计算、存储、诊断、版本化。
3. 实验平台：回测、Walk-Forward、归因、稳健性验证可复现。
4. 策略生命周期：draft → research → paper → live → retired。
5. 组合与风控：目标组合、实盘持仓、风险动作、开盘前复核。
6. 运行平台：调度、告警、日志、产物、前端统一观测。

## 非目标

- 第一阶段不接券商自动下单。
- 不做高频/盘中实时交易。
- 不为了短期收益修改 alpha 参数。
- 不引入复杂微服务、Kafka、Flink。

## 工作原则

- 每个阶段必须有 TDD 验证。
- 每个阶段必须有可回溯产物。
- 每个阶段完成后更新 `.planning/STATE.md`。
- 任何实盘相关能力先做人工确认，不自动执行。
